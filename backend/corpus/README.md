# Corpus

| File | What it is |
|---|---|
| `blocks.jsonl` | The Milestone 2 corpus: 1,001 parsed blocks from 7 documents, one JSON object per line (moved from `Docs/blocks.json`; this is the only copy) |
| `documents.json` | The document registry: title, publisher, year and URL for each `document_id` (FPS §3.3, FAP §4.2) |
| `build_report.md` | Generated by `python -m app.rag.report`: chunk counts, sizes, splits, merges and restricted chunks. Commit it with every corpus or chunker change |
| `tokenizer/bge-small-en-v1.5/tokenizer.json` | The embedder's tokenizer, vendored so chunk sizes are measured offline (see below) |

## Verifying the registry

Every citation shows the registry's title, publisher, year and link, so a wrong value is wrong in every answer from that document. **Values are never filled in from model output** (FPS §3.3), which is exactly the failure Milestone 1 recorded.

For each entry, a person opens the **original published document** and:

1. Checks `title` and `publisher` against the document. The values present now are unverified candidates: the WHO, FAO/WHO, FSA, Five Keys and Kitchen Companion titles appear in the corpus text itself, but the corpus does not name the publisher of `eatwell-guide` or `cold-food-storage`.
2. Fills in `year` (an integer, the publication or last-reviewed year shown on the document) and `url` (the official public `https://` URL). Both are `null` until then.
3. Sets `verified_by` to their name and `verified_on` to the date (`YYYY-MM-DD`).

The loader refuses any entry without `verified_by`, or without an integer `year` and an `https://` `url`, unless `ALLOW_UNVERIFIED_REGISTRY=true`. That setting is for local development only and is never set on Railway.

`aliases` are lowercase names a user might type to mean that document (used to filter retrieval to it). `publisher_aliases` are names of the publisher, used to catch a claim attributed to the wrong publisher.

## Vendored tokenizer

`tokenizer/bge-small-en-v1.5/tokenizer.json` is copied unchanged from [`BAAI/bge-small-en-v1.5`](https://huggingface.co/BAAI/bge-small-en-v1.5) at revision `5c38ec7c405ec4b44b94cc5a9bb96e735b38267a` (MIT licence), SHA-256 `d241a60d5e8f04cc1b2b3e9ef7a4921b27bf526d9f6050ab90f9267a1f9e5c66`. It is loaded with the `tokenizers` package, so the chunker counts tokens exactly as the embedder will without installing torch. If `EMBEDDING_MODEL` changes, replace this file with the new model's tokenizer.
